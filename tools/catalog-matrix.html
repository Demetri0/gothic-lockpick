Сверка базы замков

Наша база ( записей) против трёх внешних каталогов. Каждая строка — один физический замок; ячейка показывает, какой вариант конфигурации держит источник. Вариант v1 — тот, за который больше всего источников. Нажмите на строку, чтобы увидеть варианты и проверку: проходит ли наше решение на чужом варианте.

Источники

  • dsazz — gothic-remake-lockbreaker, каталог assets/catalog/locks.json, 345 замков с внутриигровыми id (FM_Chest_…_Lock). Происхождение в репозитории не указано; 276 записей совпадают с нашими байт в байт, поэтому общий источник вероятен.
  • UML — unlockmyloot, 38 страниц замков с кодом ?lock=, декодированы нашим tools/sync-uml.cjs.
  • religiosa1 — gothic-lockpick-emulator, 6 замков, записанных с игры (нумерация пластин обратная, приведена к нашей).
  • Генерируется node tools/sync-catalogs.cjs. Не включены: пресеты gothicremakelockpicking.com (6) и nkbgaming (4) — ни одна запись не совпала с другими источниками ни в одной ориентации, у nkbgaming замки на 3 пластины, которых в игре нет.
