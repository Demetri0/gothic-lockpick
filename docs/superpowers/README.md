# Design records

The `specs/` and `plans/` here are **point-in-time records** — the design and
implementation notes as they were when a feature was built. They are not kept in
sync with later changes and may reference code that has since moved or evolved.

For the current source of truth, see `CLAUDE.md`, the docs in `docs/` (`architecture.md`,
`formats.md`, `db-pipeline.md`, `user-guide.md`), the skills in `.agents/skills/`, and
the code itself.
